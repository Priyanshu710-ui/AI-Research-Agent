# Contributing to AI Research Agent

Thanks for your interest in improving AI Research Agent.

## Development flow

1. Fork the repository.
2. Create a focused branch for your change.
3. Keep secrets out of commits.
4. Make the smallest useful change.
5. Test the frontend/backend flow locally when applicable.
6. Open a pull request with a clear description of what changed and why.

## Good first contributions

- UI and accessibility improvements
- Better source/citation presentation
- Research quality improvements
- Error handling and validation
- Documentation improvements
- Test coverage
- Performance and observability improvements

## Pull requests

Please include:

- What changed
- Why it changed
- How you tested it
- Screenshots or recordings for meaningful UI changes

Avoid committing generated build output, local environments, or API keys.
